ПОЛИТИКА ОБРАБОТКИ ПЕРСОНАЛЬНЫХ ДАННЫХ

Дата публикации: 6 августа 2026 г.

Настоящая Политика определяет порядок обработки персональных данных пользователей сайта «brus16.ru» (далее – Сайт) и действует в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Регистрируясь на Сайте и используя его функциональность, Пользователь даёт своё согласие на обработку персональных данных в соответствии с настоящей Политикой.

1. Какие данные собираются

1.1. При регистрации на Сайте пользователь указывает:

  • имя пользователя (username);
  • адрес электронной почты (email);
  • пароль (хранится в хэшированном виде, недоступен Администрации).

1.2. В процессе использования Сайта сохраняются:

  • публикуемый пользователем контент (тексты статей и игр, изображения, файлы игр, комментарии). Контент может содержать персональные данные, если пользователь добавил их туда добровольно;
  • данные об авторстве контента (привязка к учётной записи);
  • код, отправленный на выполнение в IDE, сохраняется только на время обработки и удаляется сразу по её окончанию. Код не является персональными данными.

1.3. При обращении в поддержку:

  • email;
  • текст обращения;
  • вложенные файлы.

1.4. Технические логи. Сайт автоматически фиксирует IP-адрес, сведения о браузере пользователя в стандартных логах сервера (nginx). Эти данные используются исключительно для обеспечения работоспособности Сайта и не используются в иных целях.

1.5. Cookie. Сайт использует файлы cookie для хранения JWT, необходимых для аутентификации.

2. Цели обработки данных

2.1. Персональные данные обрабатываются исключительно для:

  • создания и ведения учётной записи пользователя;
  • предоставления доступа к функциональности Сайта (создание, изменение, удаление контента);
  • восстановления доступа к учётной записи (сброс пароля);
  • отправки сервисных уведомлений, предусмотренных функциональностью Сайта (публикация контента, сброс пароля, получение комментариев, удаление контента Администрацией);
  • обработки обращений пользователей в службу поддержки (ответы на вопросы, решение проблем);
  • обеспечения работоспособности Сайта (обработка технических логов).

2.2. Рекламные и иные несанкционированные рассылки не производятся.

3. Передача данных третьим лицам

3.1. Администрация не передаёт персональные данные пользователей третьим лицам.

4. Права пользователя

4.1. Пользователь вправе:

  • получить информацию о том, какие его данные хранятся на Сайте;
  • потребовать уточнения (исправления) своих персональных данных, если они неполны или неточны;
  • потребовать удаления своей учётной записи (путём обращения на почту support@brus16.ru).

4.2. При удалении учётной записи все связанные с ней персональные данные удаляются, а опубликованный контент по пожеланию пользователя может быть удалён либо обезличен (при указании пожелания в тексте обращения). По умолчанию контент обезличивается, если не указано иное.

4.3. Пользователь может в любой момент отозвать согласие на обработку данных. Отзыв согласия влечёт за собой удаление учётной записи в порядке, описанном в п. 4.2.

5. Срок хранения данных

5.1. Персональные данные хранятся до момента удаления учётной записи пользователя.

5.2. После удаления учётной записи данные уничтожаются в срок до одного месяца с даты удаления учётной записи.

5.3. Технические логи хранятся не более года с момента их фиксации.

6. Контакты

6.1. Все вопросы, связанные с обработкой персональных данных, можно направлять по электронной почте: support@brus16.ru.
