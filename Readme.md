# Сайт для учебной игровой приставки Брус-16

[https://brus16.ru](https://brus16.ru)

Полная сборка описана в docker-compose.yml.
Пример окружения описан в .env.example.

Для работы только лишь с сайтом, не включая компиляцию в IDE и отправку почты:

`pip install -r requirements.txt`

`fastapi dev`

**Backend**:

- Используется база данных sqlite3, файл brus16.db должен лежать в папке ./data.

- Модели описаны в models.py, соединение с БД в db.py, логика работы с БД в crud.py. При изменении, добавить версию в alembic.

- Основная логика реализована на fastapi, сайт реализован на принципе SSR (Server-side rendering) с Jinja2. Логика разбита на разные router-ы в папке routers.

- Все CRUD-действия реализуются с помощью форм, все формы используют библиотеку wtforms.

- Для хранения статей и игр используется папка ./media. Соответствующая логика в media.py

Для компиляции и отправке писем по почте используются worker-ы с помощью библиотеки Redis Queue (rq).

- worker.py - предоставляет функцию для компиляции, запускается как отдельный worker с nsjail в docker.
- mail.py - предоставляет функцию для отправки почты, запускается как отдельный worker в docker.

Frontend:
- Используется минимум логики, используется js и alpine.js.

Стили и вёрстка:
- bootstrap 5
- цвета из :root в ./static/style.css.

Эмулятор - компилируется из репозитория с SDL3, предоставляет функции run_from_url и run_from_bytes - запуск игры по url и из Uint8Array. Можно найти пример использования в ./templates/game.html и ./templates/ide.html через поиск.
